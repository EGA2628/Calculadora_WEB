## ✨ Funciones

- Suma, resta, multiplicación y división
- Módulo (`a % b`)
- Operaciones encadenadas (por ejemplo `2 + 3 × 4`)
- Historial de operaciones (se guarda en el navegador, con botón para borrarlo)
- Clic en un resultado del historial para reutilizarlo
- Control de errores, como la división entre 0
- Corrección de decimales (`0.1 + 0.2 = 0.3`)
- Soporte de teclado
- Diseño adaptable a celular y escritorio

## ⌨️ Atajos de teclado

| Tecla | Acción |
|-------|--------|
| `0-9` | Ingresar número |
| `+ - * / %` | Elegir operación |
| `.` o `,` | Punto decimal |
| `Enter` o `=` | Calcular |
| `Backspace` | Borrar último dígito |
| `Esc` | Limpiar todo |

## 🛠️ Tecnologías

- HTML5
- CSS3 (Grid y Flexbox)
- JavaScript (ES6+)
- `localStorage` para guardar el historial
